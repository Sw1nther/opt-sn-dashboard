# Відділ Опт СН

Базова українська односторінкова інформаційна панель для великого екрана. Оптові закупівлі та постачання пального по Україні. Це окремий проєкт, не пов’язаний з ArbiQuest.

## Поточна версія

- Офіційні щоденні курси НБУ USD/EUR, гривень за одиницю. **Не готівкові курси і не live-котирування.** Запит завжди з явною поточною датою Europe/Kyiv: API без дати після 15:30 може повертати наступний робочий день.
- Brent Europe FOB та WTI Cushing FOB: останні опубліковані щоденні спотові ціни EIA, USD/барель. Це не ф’ючерси, не пропозиції відділу і не українські оптові ціни. Графік лише за реальними останніми 22 спостереженнями; пропуски не заповнюються.
- Роздрібний орієнтир: А-98, А-95, ДП, LPG — **без чисел**, доки не погоджено надійне джерело та умови повторного використання. Посилання на Мінфін відкриває оригінальне зведення; дані Мінфіну не копіюються. А-95+ не підмінює А-98.
- Дата, київський час, повноекранний режим і адаптивний макет.
- Шестерня відкриває чесне повідомлення «Налаштування — незабаром». Жодних форм логіну, паролів, демостатистики чи імітації захисту.

## Приватність і наступний етап

GitHub Pages, код та `site/data/market.json` публічні. Тут **немає** статистики відділу, ідентифікаторів працівників, ключів доступу, облікових записів або Google Таблиць. Нічого приватного не додавати до репозиторію, статичного JSON чи GitHub Actions artifacts. Вхід для працівників, спільне редагування адміністратором та Google Таблиці — пізніше, після окремого вибору й погодження захищеного backend. Сервіси авторизації не створювались.

## Джерела та використання

1. НБУ API: <https://bank.gov.ua/ua/open-data/api-dev>; відкриті дані й умови атрибуції: <https://bank.gov.ua/ua/open-data>. Вільне повторне використання з посиланням на НБУ. На сторінці є посилання на джерело.
2. U.S. Energy Information Administration: [Brent](https://www.eia.gov/dnav/pet/hist/RBRTEd.htm), [WTI](https://www.eia.gov/dnav/pet/hist/RWTCd.htm). [Public domain / reuse](https://www.eia.gov/about/copyrights_reuse.php). Показано дату спостереження, дату випуску (якщо опублікована) та час отримання. Підписи українською підготовлені для цієї панелі, не є перекладом публікації EIA. Логотипи й фото джерел не використовуються.

## Оновлення і стійкість

Workflow `.github/workflows/pages.yml` запускається після push у `main`, вручну й щогодини на 17-й хвилині (cron — UTC; інтерфейс — Київ). Завантажує відкриті дані без сторонніх секретів, запускає тести, публікує тільки `site/` через офіційний Pages deployment. Для самого deployment використовується стандартний тимчасовий GitHub token/OIDC, не окремі збережені ключі.

Останній успішний JSON відновлюється з GitHub Actions cache; при частковій відмові джерела зберігається попереднє значення зі старою датою й статусом помилки. Якщо ще немає жодних курсів НБУ, workflow завершується помилкою й не підмінює сайт пустими значеннями. Перевірити [Actions](../../actions).

У браузері кеш перевіряється раз на 5 хв; «Оновити дані» повторно читає кеш, а не викликає постачальника. НБУ позначається неактуальним, якщо дата не сьогодні, джерело неуспішне або отримання було понад 36 год тому. EIA — якщо спостереження старше 7 днів, отримання старше 36 год або помилка джерела. Час спостереження не видається за час завантаження. GitHub cron може затримуватись; після 60 днів без активності GitHub може вимкнути розклад публічного репозиторію — увімкнути його знову в Actions.

## Локально

Потрібні Python 3.13+ і Node 24+, без npm/pip залежностей.

```sh
npm test
npm run refresh
python3 -m http.server 8080 --directory site
```

Відкрити `http://localhost:8080`. Для реального перегляду використовувати HTTP, не `file://` (ES modules і fetch).

## Публікація

GitHub Settings → Pages → Source: GitHub Actions. Push у `main` або ручний запуск workflow. Публікується `site/`, не весь репозиторій. Відносні шляхи підтримують GitHub project Pages без custom domain. Змінити вигляд: `site/index.html`, `site/style.css`; дані/стани: `site/app.js`; парсер: `scripts/refresh.py`. Перевірки: `npm test`.

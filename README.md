# Відділ Опт СН

Окремий український TV-dashboard відділу оптових закупівель та постачання пального. Не пов’язаний з ArbiQuest.

## Що показує сайт

- Справжній логотип та жовто-фіолетовий корпоративний стиль компанії, точна назва «Відділ Опт СН».
- НБУ USD/EUR у гривнях за одиницю — офіційні щоденні курси, **не готівкові і не live**.
- Датований **знімок звичайної публічної сторінки** карти АЗК компанії: роздрібні діапазони А-98 super, А-95 euro, ДП euro, LPG extra. **Не середнє по Україні, не опт, не автоматично оновлювані ціни.** Дату встановлення цін джерело не вказує. Час завантаження кешу не видається за час зміни ціни.
- EIA Brent Europe FOB і WTI Cushing FOB — останні опубліковані спотові спостереження, USD/барель. Не українські оптові ціни або ф’ючерси.
- Україна з Кримом та авторські ілюстрації автоцистерни/АЗС. Пунктирні напрямки **суто ілюстративні**, не реальні маршрути, покриття чи позиції транспорту.
- Шестерня / кнопка «Демо-статистика»: демонстраційний вхід і **синтетичні**, чітко позначені KPI. Це не справжня авторизація або захист.

## Джерела та походження

### НБУ — документований відкритий API

<https://bank.gov.ua/ua/open-data/api-dev>
Умови вільного використання з атрибуцією: <https://bank.gov.ua/ua/open-data>.

Запит із явною поточною датою Europe/Kyiv: API без дати після 15:30 може віддавати наступний робочий день. Інтерфейс показує дату курсу, час отримання та попередження про неактуальність.

### Роздріб — знімок звичайної публічної сторінки

<https://barsgroup.com.ua/map>

`site/data/retail-snapshot.json` — вручну перенесені діапазони й кількості з **видимого тексту звичайної сторінки**, повернутого WebFetch під час першого брендованого оновлення 07.11.2026. У тому результаті були видимі всі 37 АЗК та ціни, зокрема А-98 96.90 на трьох АЗК, А-95 euro 84.90–85.90, ДП euro 101.90–102.50, LPG 56.44–59.34. Точний час встановлення цін не відомий; тому зберігається лише дата спостереження, без вигаданого точного часу. Повторний WebFetch може повертати тільки оболонку клієнтської карти — це не свідчить про відсутність цін у звичайному браузері.

**Жодний недокументований endpoint компанії більше не викликається.** Автоматичний збір роздрібних цін вимкнено до погодження документованого джерела або штатного спостереження видимої сторінки. Старі значення/історія з попередньої реалізації не відновлюються з Actions cache: `refresh.py` завжди підставляє тільки перевірений репозиторний знімок. Додані згодом знімки мають походити зі звичайної видимої сторінки або документованого дозволеного джерела, з реальною датою спостереження.

А-95 premium і ДП+ не змішуються зі звичайними сортами. Не підмінювати А-98 преміальним А-95. Фактичну ціну перевіряти на АЗК.

## Демонстраційна статистика

**«Демонстраційний вхід — не захист даних».** Демо-логін `admin`. У коді лише наданий SHA-256 digest демо-пароля, без відкритого пароля. Така client-side перевірка легко обходиться; її не можна використовувати для реальних або приватних даних. Пароль не надсилається серверу, не записується у local/session storage, cookie або логи; після обробки форма очищується. Після перезавантаження демонстрація закривається.

Після входу справа на тому самому екрані відображаються 96 000 л/день, 2 480 000 л/місяць і 48 поставок/місяць — **суто вигадані приклади**, не дані компанії і не частина ринкового feed/історії. Постійно видимий напис «Приклад даних · не фактичні показники». Жодного збереження адмінських змін немає.

Справжня авторизація, статистика відділу, Google Таблиці та backend не підключені. GitHub Pages і репозиторій публічні; приватні дані не додавати в код, JSON чи deployment artifacts. Жодних облікових даних компанії, корпоративних credentials чи інтеграційних ключів у репозиторій не скопійовано.

## Автооновлення та TV

Workflow `.github/workflows/pages.yml`: push у `main`, ручний запуск, щогодини на 17-й хвилині UTC. Публікує тільки `site/`. **Автоматично оновлюються НБУ та EIA; роздріб — лише датований знімок.** У браузері кеш перевіряється кожні 5 хв, запуск і показ без взаємодії. Кнопки потрібні лише для необов’язкового демо та ручної перевірки кешу.

Для горизонтальних екранів від 1100×600 — CSS grid висотою `100svh`, без сторінкового скролу; основні курси, усі чотири ціни й карта видимі одночасно. Візуальний QA виконується координатором окремо. На мобільних адаптивний вертикальний макет.

НБУ позначається неактуальним, якщо дата не сьогодні, отримання старше 36 год або помилка. EIA — якщо спостереження старше 7 днів, отримання старше 36 год або помилка. При збоях зберігаються останні значення зі старими датами. Для роздрібного знімка завжди напис «не live». Графік роздрібної історії з’явиться лише після кількох підтверджених датованих знімків — зараз це одна точка без кривої.

GitHub cron може затримуватися, а після 60 днів без активності розклад публічного репозиторію може бути вимкнений. Джерела НБУ/EIA не потребують сторонніх секретів; deployment використовує стандартний тимчасовий GitHub token/OIDC.

## Локально й публікація

Python 3.13+, Node 24+, без npm/pip залежностей:

```sh
npm test
npm run refresh
python3 -m http.server 8080 --directory site
```

GitHub Settings → Pages → Source: GitHub Actions. Push у `main` або ручний запуск workflow. Відносні шляхи підтримують GitHub project Pages. Основні файли: `site/index.html`, `site/style.css`, `site/app.js`, `scripts/refresh.py`. Локально цієї ітерації: unit/static/HTTP тести, без браузерної автоматизації.
